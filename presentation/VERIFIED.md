# 사람용 웹의 검증 범위

대상은 `presentation/dist/index.html`과 이를 생성하는 Svelte 5 소스다. 검사 대상의 계약 버전과 원본 SHA-256은 `../generated/source_manifest.json`에서 확인한다. 웹도 이 생성 기준을 표시하며 현재 버전 번호를 이 문서에 중복 기입하지 않는다. 이 파일은 웹 검사 결과이며 상위 스키마 프로젝트의 업무 검증 결과를 대신하지 않는다.

| 검사 | 결과 | 보증 범위 |
|---|---|---|
| `npm run check` | 오류 0, 경고 0 | Svelte 5 컴포넌트의 진단 |
| `npm run build` | 성공 | JS·CSS·데이터를 포함한 단일 HTML 생성 |
| `npm run test` | 7개 통과 | 모든 Schema 제약·원본 해시 일치, 4,553개 예시 값 보존, 다운로드 Schema의 참조 완결성, 저장 API 초안 구분, 모든 화살표의 박스 내부 통과 방지, 연결 번호의 겹침 방지, 리포지토리 HTML의 모든 컴포넌트 좌표 일치 |
| `npm run test:dom` | 세부 9항목 통과 | 빌드 HTML의 DOM 생성, 지도·연결 선택, 타입 검색·근거 표시, 참조·원본 보기, 케이스·필터 이동, 주소 복원, 출력·방향 필터, 계약 제안·테마 전환 |
| `npm run test:browser` | 실행 불가 | Chromium이 페이지를 열기 전에 종료하여 실제 브라우저 검사는 수행하지 못함 |

DOM 실행 검사는 Happy DOM 에뮬레이터로 수행했다. 실제 브라우저의 시각 배치·모바일 가로 넘침·키보드 접근성·파일 다운로드 성공을 확인한 결과로 해석하지 않는다. 해당 검사기는 `tests/browser.mjs`에 포함하며 브라우저가 설치된 환경에서 별도 실행한다.

모델·업무 컴포넌트·DB를 실행하지 않았다. 예시 값의 업무 정답, 분기 정책, 저장 효과, 예시가 모든 가능한 데이터를 포함한다는 것을 보증하지 않는다. 상위 계약을 수정한 뒤에는 스키마 검증과 웹 데이터 생성·빌드·검사를 다시 실행하고 이 결과 문서도 갱신한다.
